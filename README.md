# Kheti-Hisab-Buyer-Led# 🌾 ખેતી હિસાબ — વેપારી પ્રિન્ટ

**ખેતી હિસાબ — વેપારી પ્રિન્ટ** એ ખેડૂતો માટે બનાવેલી એક સરળ, ઝડપી અને સંપૂર્ણપણે ગુજરાતી વેબ એપ્લિકેશન છે. આ એપની મદદથી તમે પાકનું વેચાણ, બોરી-બોરીના વજન (ઓકડા), વેપારી પાસેથી લીધેલા એડવાન્સ અને બાકી લેવાની રકમનો સંપૂર્ણ હિસાબ રાખી શકો છો તથા વેપારીને આપવા માટે ચોખ્ખી A4 પ્રિન્ટ કાઢી શકો છો.

## ✨ મુખ્ય સુવિધાઓ

- **⚖️ પાક વેચાણ અને ઓકડા નોંધ:**
  - **બોરી વજન (ઓકડા) મુજબ:** એક જ વેચાણમાં એકથી વધુ ગ્રેડ/લોટ (જેમ કે ગળિયા, ભુક્કો, ખખરી વગેરે) ઉમેરવાની સુવિધા.
  - **ઝડપી બોરી એન્ટ્રી:** મોબાઇલ નંબર કીપેડથી એક-એક બોરીનું વજન ઝડપથી ઉમેરી શકાય છે.
  - **ઓટો ગણતરી:** કુલ વજનમાંથી બારદાન અને ચારણ (પ્રતિ બોરી કિલો), ચોખ્ખું વજન (કિલો અને ૨૦ કિલો મણમાં), ભાવ અને વટાવ (%) બાદ કરીને ચોખ્ખી રકમ આપમેળે ગણાય છે.
  - **સીધું વેચાણ:** બોરી વજન વગર સીધા મણ અને ભાવ અથવા કુલ રકમથી પણ એન્ટ્રી કરી શકાય છે.
- **🏪 વેપારી એડવાન્સ ટ્રેકિંગ:**
  - વેપારી પાસેથી લીધેલા રોકડા કે બેંક એડવાન્સની તારીખ અને પાક મુજબ નોંધ.
  - કુલ વેચાણ સામે વેપારી પાસે કેટલા રૂપિયા બાકી લેવાના નીકળે છે તેની તાત્કાલિક ગણતરી.
- **🖨️ વેપારી પ્રિન્ટ (A4 રિપોર્ટ):**
  - માલિક, વેપારી, પાક અને તારીખ મુજબ ફિલ્ટર કરીને પ્રિવ્યુ જોઈ શકાય છે.
  - વેપારી હિસાબ સારાંશ (વેચાણ, એડવાન્સ, બાકી), ગ્રેડ મુજબ સારાંશ અને બોરી-બોરી ઓકડાની વિગત સાથે A4 સાઇઝમાં સીધી પ્રિન્ટ અથવા PDF સેવ કરી શકાય છે.
- **💾 ઑફલાઇન સુરક્ષિત અને બેકઅપ:**
  - કોઈ લોગિન કે ઇન્ટરનેટની જરૂર વગર તમામ ડેટા તમારા ફોન/બ્રાઉઝરમાં સુરક્ષિત રહે છે.
  - **JSON બેકઅપ અને Restore** સુવિધા દ્વારા ડેટા ફાઇલ તરીકે સાચવી અને બીજા ડિવાઇસમાં લઈ જઈ શકાય છે.
- **📱 મોબાઇલ અને ડેસ્કટોપ ફ્રેન્ડલી:**
  - મોબાઇલ, ટેબ્લેટ અને કોમ્પ્યુટર બધામાં સરળતાથી વાપરી શકાય તેવી ડિઝાઇન.

## 🚀 કેવી રીતે વાપરવી?

1. **વેચાણ અને ઓકડા** ટેબમાં જઈ માલિક, પાક, વેપારી અને બોરીના વજન ઉમેરો.
2. **એડવાન્સ** ટેબમાં વેપારી પાસેથી લીધેલા પૈસાની નોંધ કરો.
3. **વેપારી પ્રિન્ટ** ટેબમાં જઈ જરૂરી ફિલ્ટર પસંદ કરો અને **વેપારી પ્રિન્ટ કાઢો** બટન પર ક્લિક કરો.
